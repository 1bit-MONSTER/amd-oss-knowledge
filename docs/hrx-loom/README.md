# Loom Programming Guide (ROCm/hrx-system)

Mirror of the official Loom programming guide — `loom/docs/src/` from
[ROCm/hrx-system](https://github.com/ROCm/hrx-system) (publishes
https://rocm.github.io/hrx-system/loom/). Loom is the source-first compiler
for kernels and asynchronous device programs that HRX (Hip Runtime Extended)
uses to specialize kernels to native artifacts (HSACO) in 1–15 ms.

**Sync:** `sync-knowledge.sh` pulls the upstream clone (`~/amd-oss/hrx-system`)
and refreshes this folder; the repo's GitHub Action then refreshes Context7.
